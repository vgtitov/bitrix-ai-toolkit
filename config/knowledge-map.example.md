# Карта мест команды — образец

Скопируй в `config/local/knowledge-map.md` (не коммитится в публичный репозиторий) и заполни
своими местами. Механизм и дефолты — `docs/CONTEXT_AND_KNOWLEDGE.md`; этот файл главнее их,
потому что описывает конкретную команду.

Нет этого файла — работают дефолты, ничего не ломается.
