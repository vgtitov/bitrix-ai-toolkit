# Политика безопасности

## Сообщить об уязвимости
Нашли уязвимость (в самом toolkit или в предлагаемых им паттернах) — не открывайте публичный issue.
Напишите приватно через **GitHub Security Advisories** (вкладка Security → Report a vulnerability) этого репозитория.
Ответим в разумный срок и согласуем раскрытие.

## Область
Toolkit — про качество и безопасность кода под Битрикс. Особое внимание — правилам и проверкам, которые касаются:
- SQL-инъекций (`$DB->Query` с конкатенацией → `$DB->ForSql()`/ORM),
- XSS (вывод без `htmlspecialcharsbx()`),
- path traversal (файловые операции),
- проверки прав (`$USER->CanDoOperation()`), CSRF (`bitrix_sessid()`).

Если ast-grep/PHPStan-правило пропускает реальный класс уязвимостей или даёт ложную уверенность — это тоже баг безопасности.

## Секреты
В репозитории **не должно быть** секретов (токены, пароли, ключи вебхуков, реальные домены/данные клиентов).
Нашли утечку в истории — сообщите приватно, поможем отозвать и переписать историю. Секреты держите только в env/keychain.
