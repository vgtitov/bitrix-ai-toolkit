# Настройка доступов — что нужно, чтобы Claude мог работать сам

Какие доступы/права дать агенту и инструментам, чтобы контур работал по команде. Принцип: **секреты — только в env/keychain, НИКОГДА в чат/репозиторий/код.**

## 1. Git / репозиторий
- Доступ к репозиторию проекта (`/local` + composer + миграции) — clone/pull/push по SSH или PAT.
- **Git-хуки** ставит `scripts/install_git_hooks.py` (core.hooksPath). commit-msg чистит сообщения, pre-commit ловит N+1.
- Токен GitHub/GitLab — в env/keychain (`gh auth` или credential helper), не в команду.

## 2. Инструменты (локально)
- PHP 8.2+, Composer, ast-grep — ставит `onboard/install.sh` (нужен brew/npm/права на установку).
- Composer dev-зависимости — доступ на запись в проект (`vendor/`), сеть к packagist.

## 3. MCP-серверы
| Сервер | Доступ | Секрет |
|---|---|---|
| `bitrix-docs` (mcp-dev.bitrix24.com) | сеть (HTTP) | не нужен (публичный) |
| `serena` | локально (uvx/uv), чтение кода проекта | не нужен |
| JetBrains MCP (PhpStorm) | запущенная IDE 2025.2+ с открытым проектом | не нужен (localhost) |
| Bitrix REST (если интеграции) | вебхук/OAuth к порталу | **токен вебхука — в env**, не в код |

Подключение: `claude mcp add --transport http bitrix-docs https://mcp-dev.bitrix24.com/mcp`.

## 4. Доступ к ядру Битрикс (для проверки версий)
Агенту/PHPStan нужен **read-доступ к распакованному ядру** проекта (`bitrix/modules/`) — локально или через bitrix-ci в vendor.
Ядро не коммитим (`.gitignore`), но кладём рядом для `scanDirectories`. Прод-БД агенту НЕ нужна.

## 5. Прод и данные — границы (важно)
- Агент **не трогает прод-БД** и данные магазина; структура — только через миграции на dev/стейдже.
- Персональные данные клиентов (заказы, ФИО, телефоны) в модель **не передавать**.
- Деплой `/local` — через CI (rsync/Deployer), не агент напрямую в прод. Агент готовит изменения, человек аппрувит.

## 6. Права на запись (что агент меняет)
- ✅ `/local/**`, `config/*`, линтер-конфиги, тесты, миграции.
- ❌ ядро `/bitrix/**`, прод-конфиги с секретами, `.env` без спроса, чужие ветки без ревью.

## 7. Разрешения Claude Code (settings)
Для меньшего числа подтверждений — allowlist read-only команд (phpstan/php-cs-fixer/git status/ripgrep) в
`.claude/settings.json`. Мутирующие (push, деплой, миграции на стейдж) — оставить с подтверждением.
