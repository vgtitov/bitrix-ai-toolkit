## Известные ограничения (честно)
- `bitrix-toolkit/bitrix-ci` архивный (окт-2024) — под PHP 8.3 проверить/починить.
- ast-grep ставится отдельно (brew/npm); без него guard N+1 работает, но остальные ast-правила — нет.
- Готовых Rector-правил «старое ядро → D7» нет (семантика разная) — только апгрейд синтаксиса PHP.
- rulesync-адаптеры (cursor/copilot/…) требуют установки rulesync и конфига `.rulesync/` — пока фолбэк Claude/Gemini/Codex.
