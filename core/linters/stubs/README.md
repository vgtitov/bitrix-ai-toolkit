# Стабы — опционально (основной путь другой)

**Сначала прочти:** основной способ дать PHPStan и агенту «увидеть» ядро — **`scanDirectories` на реальное ядро
твоей версии** (см. `phpstan.neon.dist`). Он точнее стабов: ловит «этого метода нет в вашей версии» и учитывает
правки ядра. Подробно — `docs/CORE_ACCESS_AND_REPOS.md`, лестница решений.

Стабы нужны в двух случаях:
1. **Ядра нет под рукой** (правка в чужом окружении, ноутбук без дистрибутива).
2. **Надо переопределить типы отдельных функций**, чтобы убрать ложные срабатывания — например, `LocalRedirect()`
   на самом деле никогда не возвращает управление, и без стаба PHPStan считает код после неё достижимым.

Эта папка намеренно пуста: **готовых стабов в репозитории нет** — они зависят от версии ядра и являются
производной от проприетарного кода Битрикс (см. юридическую рамку в `CORE_ACCESS_AND_REPOS.md`).

## Где взять
| Вариант | Что | Ссылка |
|---|---|---|
| Готовые стабы старого ядра | `matiaspub/bxApiDocs` — самый полный набор (архив с 2022, но остаётся эталоном) | `composer require --dev matiaspub/bx-api-docs` |
| Реальное ядро пакетом | `bitrix-toolkit/bitrix-ci` — минимальная сборка ядра в `vendor/` | `composer require --dev bitrix-toolkit/bitrix-ci` |
| Сгенерировать самому | `php-stubs/generator` — делает стабы из ЛЮБОГО кода, в т.ч. из ядра твоей версии | github.com/php-stubs/generator |
| Аннотации ORM | встроенная CLI ядра — типы `getList/add/update` под твою версию | `php bitrix/modules/main/cli.php orm annotate` |

## Свой минимальный стаб (пример)
Если нужно поправить пару функций, достаточно файла на несколько строк:
```php
<?php
// bitrix.stub — переопределение типов, которые PHPStan иначе понимает неверно
/** @return never */
function LocalRedirect(string $url, bool $skip_security_check = false, string $status = "302 Found") {}
```
Положи как `core/linters/stubs/bitrix.stub` и раскомментируй `stubFiles` в `phpstan.neon`.

## Проверка
После подключения стабов прогони:
```bash
vendor/bin/phpstan analyse --no-progress
```
Ложных «Undefined class/function» стать заметно меньше. Если PHPStan ругается `file not found` — значит, путь в
`stubFiles` указывает на несуществующий файл: либо создай его, либо закомментируй строку.
